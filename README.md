# MEŞHUR TRABZON PİLAVCISI 1998 ÖZKAN USTA - Restoran Web Sitesi

## Proje Açıklaması

Bu proje, MEŞHUR TRABZON PİLAVCISI restoranı için HTML, CSS ve JavaScript kullanılarak geliştirilmiş bir web sitesidir.

## Özellikler

✅ **Anasayfa** - Etkileyici hero section ile hoş karşılama
✅ **Menü** - Restoranın tüm yemekleri ve fiyatları
✅ **Rezervasyon** - Online masa rezervasyonu formu
✅ **İletişim** - Adres, telefon, e-mail ve çalışma saatleri
✅ **Responsive Design** - Mobil, tablet ve masaüstü uyumlu
✅ **Smooth Scrolling** - Yumuşak sayfada gezinme
✅ **Form Validation** - Rezervasyon formunda doğrulama

## Dosya Yapısı

```
restoran-website/
├── index.html      # Ana HTML dosyası
├── style.css       # Tasarım ve stiller
├── script.js       # JavaScript işlevleri
└── README.md       # Bu dosya
```

## Kullanım

1. **Repository'yi klonlayın:**
   ```bash
   git clone https://github.com/herdemucar161-collab/restoran-website.git
   cd restoran-website
   ```

2. **Dosyayı tarayıcıda açın:**
   - `index.html` dosyasına çift tıklayın veya sağ tıkla → "Open with Browser"

3. **Veya live server kullanın:**
   - Visual Studio Code'da "Live Server" extension'ı yükleyin
   - Sağ tıkla → "Open with Live Server"

## Özelleştirme

### Restoran Bilgilerini Güncelleyin

**1. Adres ve İletişim Bilgileri** (`index.html` içinde):
```html
<p>Trabzon, Türkiye</p>  <!-- Adresinizi yazın -->
<p>+90 (462) XXX-XXXX</p>  <!-- Telefon numaranız -->
<p>info@meshuртrabzonpilavci.com</p>  <!-- E-mail -->
```

**2. Menüyü Değiştirin** (`index.html` içinde menu-item div'lerini düzenleyin)

**3. Renkler** (`style.css` içinde):
- Kahverengi (#8B4513) → Kendi renginize değiştirin
- Gold (#FFD700) → Vurgu renginizi seçin
